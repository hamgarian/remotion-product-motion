# remotion-product-motion v1.0.0

Goal: teach agents to create fluid, readable product showcase videos in Remotion, without prescribing a brand, camera style, platform or music track.

Inputs: a product brief, authentic interface assets/components, optional music and sound effects, duration and target format. Outputs: a shot plan, deterministic composition, rendered evidence and an honest validation report.

Acceptance:

1. The skill routes product demos and UI showcases; a fresh agent can use it on a novel brief while respecting silent/static requests and authentic content. Evidence: behavioral eval and independent review.
2. Helpers handle exponential endpoints, invalid inputs, overlapping camera movement, focal projection, hard-cut selection, cue offsets and ducking. Evidence: Node unit tests, including boundaries and fractional/out-of-order frames.
3. A standalone synthetic product example typechecks and renders in landscape and portrait; boundary-frame pixel tests demonstrate cut ghosting in a control and its absence with fixed discrete selection. Evidence: render regression script and contact sheets.
4. A clean checkout can install pinned dependencies and run the documented checks. Evidence: isolated clone verification.
5. Release artifacts include installation instructions, MIT license, changelog, logo and 1280x640 social image; the installable skill is self-contained. Evidence: packaging checks, skill validator and local install check.
6. No project branding, user paths, private data, credentials or copied proprietary assets enter the release. Evidence: secret scan and independent release review.

Non-goals: replacing Remotion documentation, claiming novel easing math or guaranteed aesthetic quality, enforcing perpetual movement, publishing client assets, or promising machine-independent rendering speedups.

Evidence starting point: prior custom motion direction and historical frame checks; public alternatives already cover camera motion, beat sync and deterministic rendering. This release is practical guidance, not a claim of unprecedented techniques. Reproduce the cut-sampling distinction before making a demonstrated-behavior claim.
