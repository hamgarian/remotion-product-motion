# Sources and provenance

The guidance and example were written for this release. They generalize lessons about layout, camera composition, temporal cut boundaries and validation without shipping the original project's code, data, branding or media. The original project and its local paths are intentionally absent.

Primary technical references, consulted 2026-10-19:

- [Remotion: flickering and deterministic rendering](https://www.remotion.dev/docs/flickering)
- [Remotion: motion blur](https://www.remotion.dev/docs/motion-blur)
- [Remotion: HTML-in-canvas motion blur](https://www.remotion.dev/docs/motion-blur/html-in-canvas-motion-blur)
- [Remotion: camera motion blur](https://www.remotion.dev/docs/motion-blur/camera-motion-blur)
- [Remotion: GPU rendering](https://www.remotion.dev/docs/gpu)
- [Remotion: renderMedia](https://www.remotion.dev/docs/renderer/render-media)
- [Web Animations: current time](https://developer.mozilla.org/en-US/docs/Web/API/Animation/currentTime)

The hard-cut recipe is a deliberate editorial distinction between discrete scene selection and continuous sampled transforms. It is not a replacement for intentional crossfades or animated UI state transitions. No superiority or novelty claim is made over Remotion or other showcase tools.

All visuals in the example are synthetic and authored in this repository. The logo and social card are original geometric graphics. No audio is bundled. Dependencies retain their own licenses; the root MIT license covers original repository material.
